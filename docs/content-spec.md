# 每题内容与完成态规约

## 必填与先想后答案

每题唯一整数id、标题、难度、domain/type/topic、官方链接与来源权利；正文必须有question、think、至少3个递进hints、explain、why、complexity、errors、exampleText、challenge、examples、boardLabel、source。算法题还需trace绑定及五语言参考。题目/例子/独立思考先呈现；提示、推演、解法和代码按用户主动展开，不自动揭答案。

题号在catalog里只是“收录”，不是“完整”。完成教学只有内容、正确性、动画、五语言参考及验证均齐，才进入可学集合；也绝不自动标记用户已完成。只有索引的题显示待完善。构建会检查结构，不代替语义与代码测试。

## 动画契约

每帧是算法真实状态的独立拷贝。读/写、集合加入、左右跳过、中点读取、边界收缩、栈进出都要对应展示代码；不把其他算法硬套同一动画。失败后不能继续读字符，空区间必须真实画空，尾插n不得读取nums[n]，覆盖补零的临时尾部残留必须解释。支持暂停、前后步、重播，切题/隐藏清理timer，低动效与44px触控。

217先查集合再加；125显式ASCII字母数字判断，直接在原串走左右指针；283五语言均为原地覆盖再补零；704/35统一闭区间left<=right、相等立即返回，缺失分别-1和left。121先用此前最低价算候选再更新最低价，26只返回k及有效前缀、尾部不补零。五语言与动画不得偷偷换模板。

复杂度必须描述参考算法。动画为倒退保存集合/数组快照的额外存储另外解释，不能把截图/过滤新串开销混称算法O(1)。

## 验证门槛

至少官方/自写主例、边界、反例及明确期望；人工推演并与独立Oracle比较。检查逐帧不变式、快照不串改，原地题必须检查传入数组。C#/Python/Java/JS/TS使用现成工具实际验证；未运行或只类型擦除、未tsc检查须明确写出，不能用伪代码充语言。

还需题目打开/例子切换/前后步/启停/重播/切题timer、路线完整度、共享计划/导入/冲突/失败状态回归。真实手机、Chrome视口、模拟DOM不能混称。一次通过的旧测试不证明新题；每批新增独立用例并记录题ID、模板和验证结果。

## 去重与许可

先查真实可学ID，已完整题不得重复覆盖；同层次选替代题并记录理由。批次清单记录新增、复用、待完善及每条路线真实完整数。每天5是内容增长目标，不限制计划或浏览。

正文/图/代码优先自写，官方链接溯源。第三方仓库的代码和教材许可分开核对，未知不得复制、整体MIT化或声称已授权商业使用。历史资料原样本地归档，不能因为用户要“整理到一起”就公开原笔记。MIT只覆盖自有项目资产。
